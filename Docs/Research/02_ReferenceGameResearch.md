# 参考游戏与相似作品调研

> 调研日期：2026-08-09
> 目的：提炼可迁移的设计规律，不把任何作品的故事、角色、视觉资产或具体谜题直接复制到《不要忘记阿黛尔》。
> 证据规则：商店/开发方页面用于确认类型和官方卖点；评测只用于辅助判断体验记忆点。`事实`、`观察`、`推论`分开记录。

## 1. 直接参考作品

### 1.1 《Yuppie Psycho》/《雅皮士精神》

- **事实**：Steam 将其描述为职场新人进入辛特拉集团并面对“能否活下来”的第一项任务，标签包括解谜、心理恐怖、探索和剧情丰富；开发者为 Baroque Decay。
- **记忆点**：把日常办公空间、等级制度和荒诞恐怖叠在一起；玩家通过调查、文件、钥匙和环境细节逐步理解企业秘密。
- **可借鉴**：将章节目标拆成一组可读、可调查、可回溯的线索；让普通物件在剧情后重新解释。
- **风险**：像素恐怖和企业讽刺是其身份核心，不适合作为本项目战争记忆主题的表层皮肤。
- **对应关系**：对应“阅读、收集品、知识锁和身份谜团”，但本项目应以潜行和心理状态为主循环。

### 1.2 《A Plague Tale: Innocence》/《瘟疫传说：无罪》

- **事实**：官方和 Steam 页面都强调阿米西亚与年幼弟弟雨果被宗教审判所和鼠群追捕，并在逃亡中建立信任；官方页面由 Focus Entertainment 维护。
- **记忆点**：儿童视角、追捕压力、脆弱的同伴关系、明确的空间路线和阶段性逃亡场景。
- **可借鉴**：把潜行压力绑定到情感目标；敌人视野、光照、声源和路线应服务剧情，而不是独立的竞技系统。
- **风险**：其同伴 AI、线性动作场面和历史背景规模较大，不能直接作为单人小团队的制作基线。
- **对应关系**：可参考警戒条和“被追捕的儿童”情绪，但《不要忘记阿黛尔》需要让玩家更多依靠四状态和掩体，而非战斗升级。

### 1.3 《Resident Evil》系列

- **事实**：系列常用文件、钥匙、物品组合、回溯路线和安全房间组织探索；《Resident Evil 2》是较适合研究其文件与地图回溯结构的代表作。
- **记忆点**：物品栏限制、文件叙事、机关钥匙链、空间记忆和返回旧区域时的新解释。
- **可借鉴**：笔记系统、收藏品列表、道具条件和“阅读后仍可查阅”的信息管理。
- **风险**：生存恐怖通常有战斗、资源压力和复杂地图；若照搬，会稀释本项目的潜行与叙事节奏。
- **对应关系**：只借鉴信息物品化和回溯结构，不采用武器资源经济作为主循环。

### 1.4 《Cairn》/《孤山独影》

- **事实**：The Game Bakers 官方页面将其定位为生存攀登游戏，重点是规划路线、管理岩钉和资源，挑战未被攀登的 Mount Kami。
- **记忆点**：风格化环境、明确的路线选择、危险与资源之间的节奏，以及“空间本身就是挑战”。
- **可借鉴**：水彩/风格化材质、简化纹理、色块和轮廓；关卡颜色可以成为心理状态的视觉语法。
- **风险**：攀登模拟的手部操作与资源管理和本项目没有直接系统对应。
- **对应关系**：主要作为美术与空间可读性参考，而不是玩法参考。

### 1.5 《Blue Prince》/《蓝途王子》

- **事实**：官方页面描述 Mt. Holly 的房间会变化，玩家选择每扇门后出现的房间；每日地图重置，永久升级和探索知识保留。
- **记忆点**：空间布局、资源选择和玩家知识共同构成进度；房间既是内容也是决策。
- **可借鉴**：知识锁、重复进入场景后的新信息、对“玩家知道了什么”的长期记录。
- **风险**：其随机房间和每日重置会带来高重玩性，本项目偏线性叙事，不应照搬随机生成结构。
- **对应关系**：为“提前发现勇气状态”“回忆场景保存知识”提供结构启发。

### 1.6 《Perception》/《感知》

- **事实**：Steam 描述盲人主角 Cassie 依靠听力和智慧探索废弃房屋；核心视觉反馈是声音帮助玩家感知黑暗环境。
- **记忆点**：信息缺失不是装饰，而是操作风险；声音成为空间可见性的来源。
- **可借鉴**：感知状态的声波、声源显形、信息逐步消退和低强度心理压力。
- **风险**：本项目主角并非盲人，若把“闭眼”做成纯粹黑屏或完全复制回声视觉，会削弱其心理记忆解释。
- **对应关系**：直接参考感知状态的范围、持续时间和声源反馈，但需要更温和、更神秘的视觉节奏。

### 1.7 《OMORI》

- **事实**：Steam 将其描述为穿越华丽与平凡世界、让被遗忘的过去重见天日的叙事 RPG，并明确包含抑郁、焦虑和自杀相关内容。
- **记忆点**：梦境、现实、情绪和过去之间的切换；重复意象和角色心理逐渐重新解释早期场景。
- **可借鉴**：回忆场景作为情绪容器；收集品、梦境 NPC 和结局信息可以同时承担安慰与提示功能。
- **风险**：其战斗、情绪属性和叙事揭示方式与本项目不同，不能把“心理主题”简化为状态数值。
- **对应关系**：主要参考回忆状态的情绪空间和“真结局信息”组织方式。

### 1.8 《Disco Elysium》/《极乐迪斯科》

- **事实**：Steam 将其描述为开放世界 RPG，玩家扮演警探，通过讯问、推理、选择和角色塑造谱写自己的篇章；其视角和绘画式城市空间是重要特征。
- **记忆点**：对白、内心声音、地点和社会关系共同构成推理；信息不是单纯任务标记，而是角色认知的一部分。
- **可借鉴**：对话选项的条件化、环境文本的角色化表达、关卡色调与叙事主题绑定。
- **风险**：其文本量、分支量和自由角色构筑规模远超本项目，必须控制对白状态与分支深度。
- **对应关系**：参考对话与阅读的内容密度，不复制技能树和开放式 RPG 结构。

### 1.9 《No Rest for the Wicked》/《恶意不息》

- **事实**：开发方将其描述为 Moon Studios 制作的精确动作 ARPG，目前以 Steam Early Access 为主要发布形态。
- **记忆点**：俯视角 3D 场景具有纵深、遮挡、层次和与战斗路径相互配合的空间表现。
- **可借鉴**：场景高度、镜头遮挡、材质层次、地形和路线共同塑造可读空间。
- **风险**：其战斗、装备、开放区域和生产规模与本项目相差很大。
- **对应关系**：仅作为俯视角 3D 场景层次和镜头构图参考。

### 1.10 RPG Maker 对话范式与《被遗忘的花园》

- **RPG Maker 范式**：底部对话框、说话者名、立绘、逐句推进和分支选项适合本项目；应采用稳定 ID、分支条件和可回滚的表格数据，而不是把对白硬编码进关卡蓝图。
- **《被遗忘的花园》**：原设计文档将其作为多线家族秘密、遗弃儿童、跨年代线索和回乡寻找身份的叙事参照。可借鉴结构，不应复制人物、国家、家族关系或情节顺序。

## 2. 相似作品对照

### 2.1 《INSIDE》

- **核心循环**：移动、观察、环境解谜、躲避追捕，几乎不依赖文字说明。
- **记忆点**：孤独儿童、工业化黑暗空间、无对白叙事和持续升级的压迫感。
- **借鉴**：用构图、动作和空间变化表达剧情；让玩家通过行为理解规则。
- **风险**：极度线性的 2.5D 节奏和无对白方式不适合承载大量身份线索。
- **对应**：借鉴“弱势儿童 + 环境叙事”，不采用完全无文本叙事。

### 2.2 《Little Nightmares》

- **核心循环**：小体型儿童在巨大载体中探索、躲藏、解谜和逃离扭曲成人。
- **记忆点**：尺度差异、掩体和追逐、童话式恐怖以及让玩家持续猜测的世界观。
- **借鉴**：把桌下、柜子、箱子等掩体做成具有情绪含义的空间；利用比例制造脆弱感。
- **风险**：怪物设计和超现实恐怖非常鲜明，直接模仿会压过战争记忆主题。
- **对应**：可借鉴掩体语言和儿童视角的可玩表达。

### 2.3 《GYLT》

- **核心循环**：女孩在扭曲小镇中调查失踪事件，使用潜行、动作、声音和视觉诱饵应对怪物。
- **记忆点**：现实欺凌与怪物恐惧互相映射；玩家可以选择躲避或直面。
- **借鉴**：让敌人机制成为心理主题的外化；声音诱饵应有明确的风险/收益。
- **风险**：其动作与怪物战斗较多，不能把勇气状态扩展成常规战斗系统。
- **对应**：最接近“儿童、心理创伤、潜行、声音诱导”组合的参考之一。

### 2.4 《The Occupation》

- **核心循环**：在固定时间窗口内调查办公场所、搜集信息、规避人员并完成访谈。
- **记忆点**：时间压力、空间路线和信息可信度共同构成调查；玩家知识会改变下一次行动。
- **借鉴**：把“知道什么”设计成可追踪进度，而不是只用钥匙开门；为知识锁提供非线性信息结构。
- **风险**：实时调查、对话和办公空间模拟复杂度高，不能直接照搬系统规模。
- **对应**：参考信息获取与路线决策的关系。

### 2.5 《The Sexy Brutale》

- **核心循环**：在重复的一天中观察事件、回溯时间、掌握时间表并阻止谋杀。
- **记忆点**：玩家知识本身就是解谜资源；同一空间在理解事件后产生新意义。
- **借鉴**：回忆与知识锁可以让玩家回到旧场景，以新状态或新线索获得不同解法。
- **风险**：时间循环是其核心承诺，本项目不应无意中变成重复试错游戏。
- **对应**：适合研究“玩家知道规则后才有解法”的设计。

### 2.6 《The Last Campfire》

- **核心循环**：探索、解决环境谜题、帮助迷失角色并继续返乡旅程。
- **记忆点**：温和的色彩、简明谜题和“寻找家园”的情感主题。
- **借鉴**：回忆状态可以暂时降低压力，成为安静的情绪恢复空间；谜题应围绕情绪或关系，而非纯机关。
- **风险**：其整体节奏舒缓，不能直接套用于持续潜行关卡。
- **对应**：参考回忆场景的安静节奏和返乡主题。

### 2.7 《The Gardens Between》

- **核心循环**：两个孩子在记忆花园中移动，利用时间变化解开每个岛屿的谜题。
- **记忆点**：时间操作既是解谜机制，也是关于友谊、童年和成长的叙事隐喻。
- **借鉴**：花朵、物件和收集品可以成为跨章节的记忆锚点；环境谜题应让玩家重新理解过去。
- **风险**：它不包含敌人潜行，不能替代警戒系统的验证。
- **对应**：为花朵意象、回忆空间和收集品叙事提供参考。

### 2.8 《Röki》

- **核心循环**：扮演托芙探索北欧奇幻世界，解谜、收集物品并寻找失去的家人。
- **记忆点**：家庭失落、童话民俗和可探索的收藏物共同推动故事。
- **借鉴**：姐姐线索、故乡意象和收集品可以同时服务导航与情感叙事。
- **风险**：其民俗世界观、角色和谜题结构不应成为本项目的视觉来源。
- **对应**：参考“寻找失散家人”的情绪目标和非战斗探索节奏。

## 3. 迁移结论

| 设计问题 | 最有价值的参考 | 对本项目的结论 |
|---|---|---|
| 如何让儿童视角产生压力 | A Plague Tale、Little Nightmares、GYLT | 压力来自暴露风险、尺度和关系，不需要大量战斗 |
| 如何让声音成为玩法 | Perception、GYLT | 声音要同时提供线索、诱饵和风险，反馈必须可读 |
| 如何做知识锁 | Blue Prince、The Sexy Brutale、The Occupation | 记录玩家获得的知识/事件，而非只记录道具 |
| 如何组织回忆 | OMORI、The Gardens Between、The Last Campfire | 回忆空间应有独立节奏和情绪功能，不只是死亡界面 |
| 如何做文件与收藏品 | Resident Evil、Yuppie Psycho、Röki | 信息必须可重读，并改变玩家对场景的解释 |
| 如何表现俯视角 3D | Disco Elysium、No Rest for the Wicked、Cairn | 轮廓、层次、遮挡和色调优先于写实材质 |
