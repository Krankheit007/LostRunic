# 地板连接与表面准备

用户已确认三级细节，并明确要求地板不要倒角、三块连在一起。

原三块地板存在少量重叠。已移除地板全部倒角，通过精确布尔并集和共面溶解生成一个连续封闭网格，沿用 FloorEnvelope 名称。保留三块的并集外轮廓、顶面高度与厚度；修改授权只针对地板。Stage03 原工程保持可回退。

地板验证：单个连通分量、零非流形边、正体积、无修改器。地板 UV0 使用每米一个 UV 单位的连续平面映射。Floor_Checker.png 的四分之一米方格在原接缝处连续，已目视核查。

其他表面准备：已将现有获准造型的圆角、加权法线、布料厚度等修改器落实为网格；保持当前 35 个 ROOT 对象的世界变换。按家具与独立道具分组生成 UV0。全场景 1022 个网格、168212 个三角面，仅作诊断。家具 UV 拉伸、岛屿利用率及方向性仍需结合正式贴图检查，不能把有限数值检查等同于完整 UV 验收。

当前仍为基础颜色预览。正式纹理、Surface 验证、独立 FBX 和回读、UE 实际游戏镜头检查尚未完成。

重建入口：通过 Blender MCP 单独打开 Stage03 工程，再执行 Tools/Blender/LivingRoom/build_stage04.py。review_stage04.py 提供 floor_check、render_scene、save；不要调用继承自旧阶段且假设三块地板仍存在的 validate，当前验证在 build_stage04.py 内完成。
